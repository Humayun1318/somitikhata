# project-roadmap.md

15 phases, each with a single clear objective. **Only Phase 1 is executed in this round** — every phase after it waits for explicit approval ("Continue to Phase 2," etc.), per the project's collaboration rule. No phase starts until its "Must be complete before starting" column is genuinely satisfied.

| # | Phase | Goal | Creates / Changes | Expected Result | Must Be Complete Before Starting |
|---|---|---|---|---|---|

## Note on `deployment.md`

Not written in detail during Phase 1, deliberately. A deployment document written before the Express backend and MongoDB schema exist would describe infrastructure for a system that doesn't exist yet, and would need a substantial rewrite once real requirements (actual data volume, actual backend resource needs) are known. Phase 15 is where `deployment.md` gets written properly and executed — at that point it should incorporate the hosting/cost comparison already produced separately for this project (VPS-based architecture, DigitalOcean/Hostinger, PostgreSQL was evaluated there for a different phase of this conversation — note that this project has since specified MongoDB as the target database, per `database-design.md`; the hosting/VPS comparison itself still applies regardless of which database engine runs on it).
